# Support

## Getting started

Begin with the [README](README.md). It explains the first campaign, the guided first scenario, map controls, local setup, and the available learning tools.

## Common questions

### Where is my progress saved?

Student profiles, journals, and campaign progress are saved in the browser on the current device. They do not sync to another browser or computer. Clearing site data can remove them, so export teacher summaries when a copy is needed.

### The page does not respond or a screen looks wrong

Reload the page once. If the problem continues, submit a [bug report](https://github.com/richie-rich90454/cascade/issues/new?template=bug_report.yml) with the browser, screen, steps to reproduce, and what you expected to happen. Do not attach student records, saved profile data, or personal information.

### How do I suggest a lesson or game improvement?

Use the [feature request form](https://github.com/richie-rich90454/cascade/issues/new?template=feature_request.yml). Explain the student or teacher need and what a successful result would look like.

### Where can I ask a setup or usage question?

Use a GitHub issue with a concise question when no existing guide covers it. For classroom questions, describe the teaching context without naming students or including their work.

## Limits

Cascade is an educational practice game, not an official College Board product. Automated writing feedback is formative and should not replace teacher review. See the [curriculum guide](docs/unit-7-coverage.md) for the coverage notes and limitations.
