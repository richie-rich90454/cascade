# Changelog

Notable changes to Cascade are recorded here. This project has not established a release cadence; dates and version numbers are added when a release is published.

## Unreleased

### Improved

- Simplified shared panels to use a full outline and clear surface instead of nested frames, corner studs, and a left-edge accent stripe.
- Expanded the map into space that was reserved for a closed sidebar.
- Added explicit MIDI file bounds checks and a forward-progress guard so malformed tracks stop with a clear error.
- Added contributor, security, support, governance, and project health guidance.
- Added automated dependency updates and a GitHub Actions quality workflow.
