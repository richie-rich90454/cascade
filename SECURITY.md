# Security policy

## Supported code

The latest code on the `main` branch is the only supported version. The project does not currently publish versioned releases.

## Report a vulnerability

Do not publish exploit steps, secrets, or sensitive vulnerability details in a public issue. If private vulnerability reporting is available for this repository, use GitHub's **Report a vulnerability** flow. If it is unavailable, open a minimal issue that asks the maintainer to arrange a private contact route; do not include exploit details in that issue.

Include the affected file or feature, the impact you observed, and the smallest reproduction that can be shared privately. Do not include real student records, browser save data, or credentials.

Cascade is a browser game that stores student profiles and progress in the current browser. Reports about local storage, imported assets, dependency updates, or unsafe links are in scope. The repository has no account system or project-operated server.

The project does not promise a response or fix timeline. The maintainer will acknowledge a report when able and coordinate public disclosure with the reporter when practical.
